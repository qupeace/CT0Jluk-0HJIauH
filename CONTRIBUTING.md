# Участие в разработке

1. Создайте ветку от develop: `git checkout -b feature/название`.
2. Вносите изменения небольшими коммитами с понятными сообщениями.
3. Перед отправкой выполните `npm run lint` и `npm test`.
4. Откройте Pull Request в ветку develop и заполните шаблон.
5. Для слияния нужны одно одобрение и успешные проверки CI.

Ошибки и предложения оформляйте через Issues по шаблонам.
