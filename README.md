# Столик Онлайн

Веб-платформа для бронирования столиков и предзаказа блюд в ресторанах.

## Концепция
Гость выбирает ресторан, дату, время и число гостей, видит свободные столики на схеме
зала, закрепляет столик и при желании формирует предзаказ блюд к назначенному времени.
Ресторан управляет залом, меню и бронями через панель администратора.

## Возможности
- регистрация, вход, личный кабинет гостя;
- каталог ресторанов с фильтрами;
- поиск свободных столиков, временное удержание столика на 15 минут;
- предзаказ блюд, привязанный к брони;
- уведомления о статусе брони по e-mail;
- панель ресторана: схема зала, меню, подтверждение и отмена броней.

- frontend/ – клиентская часть
- docs/ – архитектура, описание API, ER-диаграмма
- .github/ – шаблоны Issue и Pull Request, рабочие процессы CI

## Развёртывание
1. Клонировать репозиторий:
   git clone https://github.com/qupeace/CT0Jluk-0HJIauH.git
2. Создать файл окружения и заполнить значения:
   cp .env.example .env
3. Запустить систему:
   docker compose up -d --build
4. Применить миграции базы данных:
   docker compose exec backend npx prisma migrate deploy
5. Открыть в браузере: http://localhost:5173 (клиент), http://localhost:3000/api (сервер).

## Локальная разработка
    cd backend && npm ci && npm run start:dev
    cd frontend && npm ci && npm run dev

## Тесты и проверки
    npm run lint
    npm test

## Ветвление
main – стабильные версии, develop – разработка, feature/* и fix/* – рабочие ветки.
Изменения принимаются только через Pull Request с одним одобрением и успешным CI.
